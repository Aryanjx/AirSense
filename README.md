AirSense is an AI-based air-quality prediction and risk assessment system developed using Soft Computing techniques. It uses an Artificial Neural Network to predict the Air Quality Index based on nine pollutant parameters. We then use a Mamdani Fuzzy Inference System to evaluate the predicted AQI through six predefined fuzzy rules. Finally, centroid defuzzification generates a numerical pollution-risk score, which is displayed on the dashboard. The main objective is to combine data-driven prediction with interpretable fuzzy reasoning to provide a better understanding of air pollution.
